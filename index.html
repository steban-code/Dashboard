Monitoreo y control energético

Plataforma de supervisión que permite visualizar y almacenar las variables eléctricas de entrada y salida de la penitenciaría, mediante sensores INA219, un microcontrolador ESP32 y una API conectada a una base de datos PostgreSQL.
