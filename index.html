Penitenciaría San Serrato

Aquí las celdas se mueven solas

Proyecto ESP32 + INA219 + Servomotores

Monitoreo y control energético

San Serrato es una maqueta de cárcel cuyas celdas se abren, se cierran y se desplazan mediante servomotores controlados por un ESP32.

Los sensores INA219 miden las variables eléctricas de entrada y salida, y una API las guarda en una base de datos PostgreSQL para poder supervisarlas desde esta plataforma.
